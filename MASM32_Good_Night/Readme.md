Good Night v1.0 est un petit utilitaire Windows développé en assembleur x86 avec MASM32. Il permet de programmer l’arrêt ou le redémarrage automatique de l’ordinateur après un délai défini par l’utilisateur, avec compte à rebours, interface graphique et intégration dans la zone de notification Windows.


Langage : Assembleur x86 (MASM32)
Plateforme : Windows
Interface : Win32 API
Fonctions principales : Shutdown, Reboot, Timer, System Tray
